================================================================================
  IVR de turnos — instalar desde el repositorio
  Issabel / CentOS 7 / Asterisk 11
================================================================================

Qué es
------
Un IVR de telefonía IP: la llamada SIP entra a Asterisk, se reproduce el
audio del día (según un calendario web) y, si el que llama marca 1, se
desvía al teléfono de ese destino.

Pensado para farmacia de turno. Sirve igual para guardias, sucursales,
técnicos u otro anuncio que cambia cada día. En el panel se llaman
«farmacias»: son destinos con audio y teléfono.


Flujo
-----
  Telefono / DID / tecla de IVR
       -> Issabel (SIP)
       -> destino personalizado  farmacia-turno,s,1
       -> audio del dia
       -> tecla 1 = desvio al telefono de ese destino

  Panel  http://IP-DE-TU-CENTRAL:8787
  Timer  00:05  publica el dia en Asterisk (AstDB)


================================================================================
Instalar (en la central, como root)
================================================================================

  yum install -y git
  git clone https://github.com/emirovetto/IVRIPE.git /opt/src/IVRIPE
  cd /opt/src/IVRIPE

Elegi un interno LIBRE (ejemplo 8000) y no lo crees en la GUI:

  EXTEN=8000 bash install.sh

La primera vez puede tardar 10-20 min (Python 3.9 en /opt/python39).
No reemplaza el Python de Issabel.

Al terminar: panel http://IP-DE-TU-CENTRAL:8787
  usuario admin / admin  (cambiarla en Sistema)


Issabel (GUI, una vez)
----------------------
  PBX -> Destinos personalizados
    Destino:  farmacia-turno,s,1
  Aplicar cambios.

  Ruta de entrada, tecla de IVR, o el interno elegido -> ese destino.

  NO crear ese interno como extension/usuario en Issabel.


Panel (primer uso)
------------------
  1) Cambiar clave admin
  2) Destinos (Farmacias): nombre, telefono como se marca desde un interno
  3) Audios: intro, fallback, un WAV por destino
     Opcional: opcion1 («para comunicarse marque 1»)
  4) Turnos: cargar el mes
  5) Hoy -> Publicar ahora

Todos los dias: nada. A las 00:05 el timer publica el dia.
Si cambia HOY: Publicar ahora.


================================================================================
Dónde queda
================================================================================

  Panel          /opt/ivr-farmacias
  Base           /var/lib/ivr-farmacias/ivr.db
  Claves         /etc/ivr-farmacias.env
  Dialplan       /etc/asterisk/extensions_farmacias.conf
  Audios         /var/lib/asterisk/sounds/es/farmacias/
  Timer          ivr-farmacias-diario.timer


================================================================================
Comprobar
================================================================================

  bash /etc/asterisk/farmacias/verificar.sh
  systemctl is-active ivr-farmacias
  systemctl list-timers --all | grep ivr
  asterisk -rx "database get farmacias hoy"
  asterisk -rx "dialplan show farmacia-turno"

Llamar al interno de prueba: intro + audio del dia. Tecla 1: desvio.


================================================================================
Actualizar desde git
================================================================================

  cd /opt/src/IVRIPE
  git pull
  bash install.sh

O copiar web/ a /opt/ivr-farmacias/web/, chown asterisk, restart del servicio,
Guardar interno en Sistema y Publicar ahora.


================================================================================
Notas Issabel / CentOS 7
================================================================================

  - No usar yum install python3 (es 3.6 o no existe)
  - El instalador apunta yum a Vault y compila Python 3.9 con SSL
  - cron.d tiene que ser ASCII; el timer systemd es el cambio de dia
  - El archivo extensions_farmacias.conf debe ser de usuario asterisk
  - El numero de desvio se marca como desde un interno de esa central
